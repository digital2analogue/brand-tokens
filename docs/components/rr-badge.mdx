## Overview

Use `rr-badge` for a compact, non-interactive status marker or a decorative accent chip — the small pill that labels a row, item, or section. The status variants (`success`, `warning`, `danger`, `info`) carry semantic meaning; the `accent-*` variants are purely decorative emphasis. Reach for `rr-tag` when the label is user-removable or represents a filter, and `rr-alert` when the message needs a full-width banner rather than an inline pill.

## Accessibility

- **WAI-ARIA pattern:** [www.w3.org/WAI/ARIA/apg/patterns/badge/](https://www.w3.org/WAI/ARIA/apg/patterns/badge/)
- **Focusable:** no
- **WCAG:** 1.4.3 Contrast (Minimum), 1.4.11 Non-text Contrast

**Rules**

- Add role="status" on the host element when badge content updates dynamically to create an ARIA live region.
- Decorative badges (accent-*) do not need role="status"; they are static labels.
- Badge text alone must convey meaning; do not rely solely on color to distinguish variants.

## Guardrails

- Never use hex values. Always use var(--color-*)
- Never reference --primitive-* tokens in component code
- All text/background pairings must pass WCAG AA (4.5:1)
- Variants use a subtle style: a tinted background with accent-colored text, not a solid fill. The variant foreground is the accent color itself (e.g. foreground-accent-green), not foreground-on-{variant}.
- To make a variant solid instead (bright fill + dark text), point the variant's styles in badge.ts at background-{variant} and foreground-on-{variant}.
{/* GEN:guardrails:end */}

## Usage

- **Do** keep labels to a word or two — a badge is a marker, not a sentence.
- **Do** add `role="status"` when the badge's content updates live (e.g. a connection state) so assistive tech announces the change.
- **Don't** rely on color alone to distinguish variants — the text must carry the meaning (a `danger` and a `success` badge must still read differently with color removed).
- **Don't** use a badge for anything clickable — it isn't focusable; use `rr-button` or `rr-tag` for interactive affordances.
