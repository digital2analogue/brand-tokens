## Overview

`rr-segment` is one choice inside [`rr-segmented`](./rr-segmented). It exists to
be restrained: it renders a `role="radio"` button, and it paints **no chrome of
its own** — no fill, no border, no shadow, only its label colour.

The parent owns everything else. It writes `selected` and `tab-stop` on every
sync, and it draws the single sliding indicator that sits behind the chosen
segment.

## Accessibility

- **WAI-ARIA pattern:** [www.w3.org/WAI/ARIA/apg/patterns/radio/](https://www.w3.org/WAI/ARIA/apg/patterns/radio/)
- **Focusable:** yes
- **Keyboard:** Enter or Space activates the focused segment via its native button; Arrow keys are handled by the parent rr-segmented, not here
- **WCAG:** 1.4.3 Contrast (Minimum), 2.1.1 Keyboard, 2.4.7 Focus Visible, 4.1.2 Name, Role, Value

**Rules**

- aria-checked and the roving tabindex are managed in concert with rr-segmented.
- Host uses delegatesFocus so focus forwards to the inner button.
- The focus ring is inset rather than outset: the segment sits inside the track's rounded edge, where an outset outline would be clipped.
- Unselected labels use foreground.muted, which clears AA on the track (6.3:1 base dark) — the system's sub-AA foreground.inactive is decision-engine-only chrome and is deliberately not used here (#232).

## Guardrails

**System rules** — how each is enforced in parentheses; `manual` means nothing checks it for you.

- `hard-1` _(lint)_ — No hardcoded colors — use var(--color-*) custom properties
- `hard-6` _(gate)_ — All text must meet WCAG AA contrast (4.5:1) against its background — all pairings in the system already do; do not introduce new ones without checking
- `hard-9` _(lint)_ — Never use primitive tokens (color.green.*, space.*, font.size.*) in UI code — always go through the semantic layer
- `hard-10` _(lint)_ — Motion must respect `prefers-reduced-motion` (WCAG 2.3.3). The built brand CSS zeroes `--motion-duration-*` under `reduce`, so token-driven transitions stop automatically — never hardcode a transition/animation duration that bypasses the tokens. Any infinite animation (spin, shimmer, pulse) cannot be reached by the token override and MUST carry its own `@media (prefers-reduced-motion: reduce)` guard that stops or damps it

**Using rr-segment**

- Do not set selected or tab-stop directly — control the chosen segment via rr-segmented[value]. Both are written by the parent on every sync.
- A segment paints no chrome of its own: no fill, no border, no shadow. That restraint is the component — two segments that each drew a box would read as two adjacent buttons instead of one field with one value.
- tone colours the label when this segment is chosen, and the parent lifts the same tone onto the indicator. The set is neutral, success and danger only: a two- or three-choice control can carry a binary verdict (approve/deny, pass/fail, on/off) and nothing more. warning and info are message roles — they describe something the system is telling you, not a choice someone made. A third outcome that genuinely needs its own colour (decision-engine's Review) should get its own tone added deliberately, not borrow a feedback role.

## Usage

**Do** control the chosen segment through `rr-segmented[value]`. `selected` and
`tab-stop` are written by the parent on every sync, so anything you set on them
directly is overwritten.

**Do** use `tone` only where the value has a semantic reading of its own — an
approve/deny outcome, a pass/fail status, an on/off setting. Leave it `neutral`
otherwise; a tinted pill on an ordinary preference is noise.

There are three tones and there is no fourth. A third outcome that genuinely
needs its own colour — decision-engine's Review — should get a tone added
deliberately rather than borrowing `warning` or `info`, which name feedback
messages, not choices.

**Don't** style a segment with a background, border or shadow. That restraint is
the component: the moment two segments each draw a box, the control reads as two
adjacent buttons rather than one field holding one value.

**Don't** use a segment outside `rr-segmented`. On its own it is a `radio` with
no group to name it, no roving tabindex and no indicator.
