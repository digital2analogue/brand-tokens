## Overview

Use `rr-avatar` as the identity mark for a person or entity — comment rows, assignee chips, account menus. It renders initials on a bold accent fill by default and swaps to an image when `src` is set (initials remain the fallback if the image fails). The `color` variants map to the `*-bold` accent fills, whose white-text pairings are contrast-checked (5.0:1+); pick per-identity deterministically (hash the name) rather than randomly so the same person keeps the same color. Provide `img-alt` when the image carries meaning; decorative avatars next to a visible name should keep empty alt.

## Accessibility

- **WAI-ARIA pattern:** [www.w3.org/WAI/ARIA/apg/patterns/](https://www.w3.org/WAI/ARIA/apg/patterns/)
- **Focusable:** no
- **WCAG:** 1.1.1 Non-text Content, 1.4.3 Contrast (Minimum), 1.4.11 Non-text Contrast

**Rules**

- Initials avatars expose role=img with aria-label set to name; the initials text itself is aria-hidden
- Image avatars derive alt from the alt prop, falling back to name
