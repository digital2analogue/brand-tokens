## Overview

Use `rr-alert` for an inline, in-flow notification that belongs to the page — success confirmations, validation summaries, warnings, service notices. It stays where it's rendered and pushes content down; for a transient floating notification that announces itself and leaves, that's a toast (not yet in the system). Pick the `variant` by meaning, not color: success/warning/danger/info map to the feedback token families, and the amber/red/blue text-on-tint pairings are pre-checked for AA. `dismissible` adds a close button and fires `rr-alert-dismiss`; without it, the alert is permanent until you remove it. Don't rely on the color alone — give it a `heading` or an icon so the severity survives color-blindness and grayscale.

## Examples

### Success

```html
<rr-alert variant="success" heading="Saved">Your changes were saved.</rr-alert>
```

### Danger, dismissible

```html
<rr-alert variant="danger" heading="Upload failed" dismissible>The file could not be processed.</rr-alert>
```

### Info with icon

```html
<rr-alert variant="info" heading="Heads up">
  <rr-icon slot="icon" name="info"></rr-icon>
  Maintenance is scheduled for tonight.
</rr-alert>
```

## Accessibility

- **WAI-ARIA pattern:** [www.w3.org/WAI/ARIA/apg/patterns/alert/](https://www.w3.org/WAI/ARIA/apg/patterns/alert/)
- **Focusable:** no
- **Keyboard:** Tab moves focus to the dismiss button when dismissible; Enter or Space activates the dismiss button
- **WCAG:** 1.4.3 Contrast (Minimum), 1.4.11 Non-text Contrast, 4.1.3 Status Messages

**Rules**

- Do not rely on color alone to convey the alert variant — pair with a heading or icon
- The dismiss button carries an aria-label of "Dismiss"
